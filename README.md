# Hokm

A multiplayer Hokm card game for Android, built by Yameen.

- Play with friends in private rooms (room codes, no account needed)
- Live group voice chat between seated players
- Works as an Android app (APK)

## Install

1. Download `downloads/hokm-game-v2.0.apk` to your phone.
2. Open it and allow "Install unknown apps" if Android asks.
3. Open Hokm, create a room, and share the room code with friends.
4. Tap **Mic** to talk. Android will ask for microphone permission once.

Requires Android 8.0 or newer.

## What is in this repo

- `downloads/` – the installable app
- `android-wrapper/` – the small Android shell (WebView + microphone permission) that hosts the game
- `assets/` – app icon

The game's own code is not published here.
