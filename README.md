# Hokm for Android

A multiplayer Hokm card game for Android, built by Yameen.

## Features

- Play with friends in private rooms using room codes.
- No account required.
- Live group voice chat between seated players.
- Android app distributed as an APK.

## Download and install

1. Open the APK file in this repository: `hokm-game-v2.0.apk`.
2. Download it to your Android phone.
3. Open the downloaded APK. If Android asks, allow your browser or file manager to install unknown apps.
4. Follow the installation prompts, then open Hokm.
5. Create a room and share its room code with your friends.
6. Tap **Mic** to use voice chat and grant microphone permission if prompted.

**Android requirement:** Android 8.0 or newer.

> Only install APKs you trust. Android may show a warning because the app is being installed outside the Play Store.

## Repository contents

The files currently included at the repository root are:

- `hokm-game-v2.0.apk` — installable Android application.
- `MainActivity.java` — Android activity source file.
- `AndroidManifest.xml` — Android app manifest.
- `icon.png` — app icon.
- `.gitignore` — Git ignore rules.
- `LICENSE` — usage and rights notice.

The complete game implementation is not published in this repository. The presence of some Android wrapper files does not mean the full game source code is available.
